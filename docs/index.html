01

Overview

LPSN-MCP is a bridge between large language model (LLM) assistants that support the Model Context Protocol and the LPSN prokaryotic nomenclature database. It allows an AI assistant — such as Claude Desktop, Cursor, or any MCP-compatible client — to interact with prokaryotic taxonomic data in real time.

All data is fetched live from the public LPSN website at https://lpsn.dsmz.de/. No API key or registration is required.

Search

Search for prokaryotic names (bacteria and archaea) by full or partial name.

Retrieve

Get detailed information about any taxon — etymology, type strain, status, synonyms, and more.

Classify

Obtain the full classification lineage from domain down to species for any name.

Browse

Browse taxa by taxonomic rank — domain, phylum, class, order, family, genus, species.

02

What is LPSN?

The List of Prokaryotic names with Standing in Nomenclature (LPSN) is a publicly available, curated database maintained by the Leibniz Institute DSMZ. It provides up-to-date information on all prokaryotic names (Bacteria and Archaea) that have standing in nomenclature under the International Code of Nomenclature of Prokaryotes (ICNP).

Taxonomic classification

The classification of each named taxon within the prokaryotic tree of life.

Nomenclatural status

Whether a name is validly published, illegitimate, rejected, or under other standing.

Etymology

The etymological derivation and meaning of each prokaryotic name.

Type strains & species

Reference type strains and type species associated with each taxon.

Synonyms & basonyms

Alternative names, synonyms, and previously validly published basonyms.

References

Links to IJSEM validation lists and other effective publication sources.

LPSN is widely used by microbiologists, taxonomists, bioinformaticians, and students worldwide.

03

Available Tools

The server exposes 7 tools through the Model Context Protocol. Each tool is callable by any MCP-compatible AI assistant.

# Tool Description
1 search_taxa Search for prokaryotic names by full or partial name.
2 get_taxon_detail Get full detail for a specific taxon — etymology, type strain, synonyms, etc.
3 get_classification Get the complete lineage from domain to the target taxon.
4 browse_by_rank Browse all taxa at a given rank, optionally filtered by first letter.
5 get_nomenclature_info Read the nomenclature rules page from LPSN.
6 get_classification_info Read the classification information page from LPSN.
7 get_text_page Read any LPSN informational text page by path.

Usage Examples

Once configured, you can ask your AI assistant natural-language questions such as:

“Search LPSN for Escherichia coli”
“Get detailed information about the genus Bacillus from LPSN”
“What is the full classification of Methanococcus jannaschii?”
“Browse all families in LPSN starting with the letter 'A'”
“What are the prokaryotic nomenclature rules according to LPSN?”

Installation & Configuration

Prerequisites

  • Node.js ≥ 18.0.0 (native fetch and AbortController)
  • npm ≥ 9.0.0 (or pnpm / yarn)

Clone & Build

# Clone the repository
git clone https://github.com/ZengZichao/LPSN-MCP.git lpsn-mcp
cd lpsn-mcp

# Install dependencies
npm install

# Compile TypeScript to dist/
npm run build

Configure in Claude Desktop

Add the following to your claude_desktop_config.json:

{
  "mcpServers": {
    "lpsn": {
      "command": "node",
      "args": [
        "/absolute/path/to/lpsn-mcp/dist/index.js"
      ]
    }
  }
}

Configure in Cursor

{
  "mcp.servers": {
    "lpsn": {
      "command": "node",
      "args": ["/absolute/path/to/lpsn-mcp/dist/index.js"]
    }
  }
}

Available Scripts

Command Description
npm run build Compile TypeScript to dist/
npm run start Run the compiled server
npm run dev Run with tsx (no compilation needed)
06

Limitations & Disclaimer

1

Unofficial project

This is an unofficial, community-driven MCP server, not affiliated with or endorsed by DSMZ or LPSN.

2

Web scraping, not an official API

Data is obtained by parsing public LPSN HTML pages. If the page layout changes, parsing may break.

3

Rate limiting

LPSN is a public resource. Please use this tool responsibly and avoid excessive requests.

4

No warranty

Data is provided "as is" from LPSN. Always verify critical information on the official website.

5

Network dependency

The server requires an active internet connection to reach https://lpsn.dsmz.de/.
